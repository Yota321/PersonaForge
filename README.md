# Forge

A privacy-first adaptive personality platform.

Forge analyzes how you think, communicate, make decisions, solve problems, and connect with other people using an adaptive assessment that runs entirely inside your browser.

No accounts.
No cloud processing.
No tracking.
No data collection.

Everything happens locally on your device.

---

## Overview

Forge combines multiple psychological frameworks into one adaptive personality system instead of simply recreating MBTI or DISC.

Every assessment generates a rich personality profile including:

- Primary Archetype
- Full Archetype Ranking
- Hidden Trait Radar
- Career Matches
- Relationship Analysis
- Compatibility Reports
- Communication Style
- Leadership Style
- Growth Areas
- Fantasy Roles
- Narrative Roles
- Personality Stability
- Match Confidence
- Personality Code
- Shareable Profile

---

## Features

### Adaptive Assessment

The assessment is designed to become more confident as it learns about the user.

- Starts with foundational questions
- Adapts based on previous answers
- Stops early if confidence is high
- Maximum of 50 questions
- Entirely client-side

---

### Personality Engine

Forge measures dozens of personality dimensions and combines them into unique archetypes.

Current system includes:

- 30 Archetypes
- 25 Hidden Dimensions
- Career Matching
- Relationship Profiles
- Social Analysis
- Learning Styles
- Decision Styles
- Stress Responses
- Fantasy Profiles
- Entertainment Preferences

---

### Compatibility

Compare two Forge profiles to discover

- Shared strengths
- Complementary traits
- Potential conflicts
- Friendship compatibility
- Romantic compatibility
- Business compatibility
- Gaming compatibility
- Creative compatibility

---

### Privacy

Forge is designed around one principle:

Your personality belongs to you.

No accounts.

No analytics.

No ads.

No servers.

No tracking.

Results are generated entirely inside your browser.

---

## Sharing

Forge profiles can be shared using portable personality codes and direct profile links.

Anyone with a shared profile can

- View the profile
- Compare with their own
- Take the assessment themselves

---

## Technology

Forge is built as a completely client-side web application.

- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)
- GitHub Pages

No backend required.

## Philosophy

Forge is not designed to put people into boxes.

It is designed to help people understand themselves better, discover patterns in how they think, and compare those patterns with others in meaningful ways.

Every result is a snapshot, not a label.

People evolve.

Forge evolves with them.
