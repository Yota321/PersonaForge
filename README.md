# PersonaForge

Discover how you think, connect, lead, create, and grow.

PersonaForge is a privacy-first adaptive personality platform that runs entirely inside your browser.

No accounts.
No servers.
No tracking.

Your personality belongs to you.

Answer as few as 35 carefully selected questions and receive a rich personality profile, relationship insights, career matches, fantasy roles, compatibility reports, and a portable personality code you can share with friends.

Everything happens locally.

Forever.
